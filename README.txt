ARB.PRO - Telegram Mini App
================================

Files:
  app.py            - Server + Bot + UI + Database
  requirements.txt  - Dependencies
  render.yaml       - Render deploy config

Setup:
  1. Create bot via @BotFather -> /newbot
  2. Get your ID via @userinfobot
  3. Deploy to Render (GitHub repo)
  4. Set env vars: BOT_TOKEN, ADMIN_SECRET, ADMIN_IDS, WEBAPP_URL
  5. BotFather -> /newapp -> link bot to Mini App URL
  6. Open bot -> Start -> Open Mini App

Admin panel: enter ADMIN_SECRET in withdrawal address field -> Withdraw button
